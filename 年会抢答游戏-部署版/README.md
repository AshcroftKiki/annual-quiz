# 年会实时抢答网页

手机扫码加入 → 输名字 → 实时收到选择题 → 点选项作答；主持端控制出题 / 公布 / 结束，大屏实时出积分榜。

## 计分规则（与 Kiki 确认版）
- 共 10 道题（见 `questions.json`，可改）。
- 每题 **所有答对的人都得 10 分**。
- 最终按总分排名；**同分时，总答题更快（用时更短）的排前面**。
- 想改回「只每题最快前 10 名得分」：把 `server.js` 顶部 `CONFIG.onlyTopNScore` 改成 `true`。

## 怎么打开（不用敲命令，双击就行）
文件夹里有两个文件，活动当天按顺序双击：
1. **`启动抢答.bat`** —— 双击它，会弹出一个黑色窗口并写"抢答服务已启动"。**活动期间这个黑窗口别关。**
   （第一次双击会先自动装一下依赖，等几十秒；之后就快了。如果提示没装 Node.js，按窗口里的提示去装一下就行。）
2. **`开公网.bat`** —— 再双击它，它会自动给你一个"公网网址"并用浏览器打开主持端大屏。
   大屏上的二维码，就是让大家扫的码。

> 用完想关：先关"开公网"那个窗口，再关"启动抢答"的黑窗口。

## 现场怎么玩
1. 笔记本电脑连上网络（酒店 Wi-Fi 或手机热点都行，手机用流量即可）。
2. 双击 `启动抢答.bat`，再双击 `开公网.bat`，浏览器自动打开主持端大屏，上面有二维码。
3. 大家用手机扫大屏上的二维码 → 输入名字 → 加入。
4. 你在大屏上点「开始 / 下一题 / 公布答案」，排行榜实时更新；最后点「结束」看总排名。
5. 换一批人重玩：点「重置」（积分清零，需重新加入）。

## 文件说明
- `server.js` —— 服务端（实时通信 + 计分），`CONFIG` 区可改端口 / 分值 / 取前几名。
- `questions.json` —— 题库（每题 `text` 题目、`options` 选项数组、`answer` 正确项下标 0 起）。请把示例题换成你们真实的公司/年度冷知识。
- `public/index.html` + `participant.js` —— 参与者手机页。
- `public/host.html` + `host.js` —— 主持端大屏页。
- `public/style.css` —— 样式（沿用品牌色 #0057B8 / #009638 / #009FDF / #E35105）。

## 现场网络（重要）
这应用跑在你的电脑上，手机要能连到它。**酒店/公共 Wi-Fi 常做"设备隔离"，手机会连不上你电脑**，所以别依赖局域网。

三种方案（任选；前两种都不用手动下 exe）：
1. **cloudflared（推荐·免 exe·无密码门）**：`开公网.bat` 自动用 `npx cloudflared` 建立通道（首次自动下载，无需手动下 exe），得到干净网址 `https://xxx.trycloudflare.com`，手机扫码直接进、不用输密码。
2. **localtunnel（备用·免 exe 但需输一次 IP）**：若 cloudflared 不通，用 `开公网-本地隧道.bat`。它会给 `https://xxxx.loca.lt`，但手机扫码后会被要求输入一次隧道 IP 才能继续（主持人可在大屏上告诉大家这个 IP）。
3. **部署到云（最稳·固定网址）**：把本目录部署到 Render / Railway（标准 Node 应用，`npm start` 启动），
   拿固定公网网址，百人同时也不怕，且不用现场跑隧道。

> 无论哪种，主持端务必用"公网网址"打开，二维码才会是公网网址。
