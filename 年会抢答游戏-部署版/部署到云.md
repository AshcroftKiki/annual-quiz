# 年会抢答游戏 · 部署到云（傻瓜版）

> 目标：拿到一个**固定网址**（例如 `https://annual-quiz.onrender.com`）。
> 大屏打开 `网址/host.html`，大家手机扫 `网址/` 就能玩。
> 全程不用装软件、不用输命令、不用记 IP。年会当天 100+ 人同时扫码也没问题。

---

## 准备工作（只做一次）

把文件夹 `年会抢答游戏-部署版` 整个拷到一台能上网、能登录网页的电脑上（U盘/微信文件传输助手都行）。
**注意：不要上传 `node_modules` 文件夹**（那个是本地测试用的，云端会自动安装，太大也传不上去）。

---

## 第 1 步：注册 GitHub（免费）

1. 打开 https://github.com ，点右上角 **Sign up（注册）**。
2. 填邮箱、设密码、取个用户名，跟着提示点完，去邮箱点验证链接激活。
3. 注册完登录进去就行。免费档够用，万一提示要绑卡做身份验证，按提示操作即可（免费档不会扣费，可随时删服务）。

## 第 2 步：新建一个空仓库

1. 登录后，点页面右上角 **+** 号 → 选 **New repository（新建仓库）**。
2. 仓库名随便起，比如 `annual-quiz`（只能英文/数字/横杠）。
3. **关键**：下面三个勾都**不要**打：
   - ☐ Add a README file（不要）
   - ☐ Add .gitignore（不要）
   - ☐ Choose a license（不要）
4. 点 **Create repository（创建仓库）**。

## 第 3 步：把游戏文件传上去

1. 建好后会看到一个「快速上手」的空白页面。把 `年会抢答游戏-部署版` 文件夹里的**所有内容**一次性**拖进网页里那个虚线框**（直接拖文件夹进去就行，会自动保持层级）。
2. 拖进去后，页面下方出现文件列表。
3. 最底下「Commit changes」那栏，说明随便写 `init`，点 **Commit changes** 按钮。
4. 等几秒刷新，能看到这些文件就成功了：
   `server.js` `package.json` `render.yaml` `questions.json` `public/` 等。

## 第 4 步：在 Render 一键部署（免费）

1. 打开 https://render.com ，点 **Sign Up**，选 **Continue with GitHub**（用 GitHub 登录，会跳去授权，点允许）。
2. 登录进 Render 后台后，点右上角 **New +** → 选 **Blueprint**（蓝图）。
3. 第一次会让你连 GitHub，点 **Connect** 选刚才那个仓库 `annual-quiz`，授权。
4. 连上后 Render 会自动读到你仓库里的 `render.yaml`，直接点 **Apply / Deploy Blueprint**。
5. 等待 1~2 分钟（首次会转圈装依赖），状态变成 **Live（绿色）** 就部署好了。
6. 页面上会出现一个网址，形如 `https://annual-quiz.onrender.com` —— **这就是你的固定网址，年会当天一直用这个**。

> 小提示：免费档服务在没人访问 15 分钟后会「休眠」，第一次打开要等约 30 秒唤醒。
> 年会当天**提前 10 分钟**把大屏页打开，它就被唤醒了，全程不卡。

---

## 第 5 步：年会当天怎么用

1. 大屏电脑（接投影的那台）浏览器打开：`https://你的网址.onrender.com/host.html`
   → 这个页面有二维码 + 出题/下一题/公布答案/结束 的控制按钮。
2. 大家手机扫码（扫同一个大屏上的二维码，自动指向这个网址）→ 输名字 → 开始抢答。
3. 主持人在大屏上点「开始 / 下一题 / 公布答案」，所有人的手机同步跳题。
4. 10 题答完点「结束」，大屏展示总分排行榜（同分按答题速度排前）。

## 常见问题

**Q：网址会换吗？**
A：不会。只要不删仓库和 Render 服务，这个网址一直是你的，明年还能复用。

**Q：要花钱吗？**
A：免费档完全够用一整晚。如果担心人多卡，可在 Render 后台把 plan 升到 Starter（$7/月），用完可随时删。

**Q：题目想换成公司真实内容怎么办？**
A：改 `questions.json` 这个文件（里面是 10 道题，照着格式改文字和正确答案序号即可），改完在 GitHub 里重新提交，Render 会自动重新部署。也可以让我帮你改。

**Q：GitHub 拖文件夹失败 / 传不上去？**
A：把文件夹里的文件**一个一个**拖进虚线框也行；或者先建好仓库后，用 GitHub 网页的「Add file → Upload files」逐个上传（注意 `public` 是个文件夹，要展开把里面 5 个文件一起传）。
